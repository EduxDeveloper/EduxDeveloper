## Sobre mi

Soy Salvador Eduardo Martinez Zuniga, tambien conocido como EduxDeveloper. Me gusta construir proyectos practicos, conectar interfaces con APIs reales y trabajar tanto el frontend como el backend.

En mis repositorios publicos se nota una base fuerte en JavaScript, React y desarrollo de APIs, junto con proyectos en Java. Tambien trabajo con Java usando Maven y Spring Boot, bases de datos Oracle 21c y el stack MERN para aplicaciones full stack.

## En que trabajo

- Desarrollo de APIs REST con Node.js, Express y Java Spring Boot.
- Aplicaciones frontend con React, componentes reutilizables y navegacion con React Router.
- Proyectos full stack con MERN, integrando frontend, backend y base de datos.
- Practicas con integraciones reales como Cloudinary, Wompi, Retool y despliegues en Render.
- Bases de datos relacionales con Oracle 21c y modelos orientados a backend empresarial.
